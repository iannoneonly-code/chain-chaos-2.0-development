# Chain Chaos – Paket Web

## Isi paket
- `index.html` — file utama game Chain Chaos.

## Cara menjalankan
1. Ekstrak ZIP.
2. Buka `index.html` di browser, atau unggah isi folder ini ke repository GitHub Pages.

## Catatan aset
Pemeriksaan file sumber menunjukkan bahwa CSS dan JavaScript ditulis langsung di dalam `index.html`, dan tidak ada gambar atau file CSS/JavaScript lokal terpisah yang dirujuk.
Font Space Grotesk dimuat dari Google Fonts, sehingga font tersebut memerlukan koneksi internet. Game tetap memiliki file utama HTML di dalam paket ini.
